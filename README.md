# 🚌 LUXEVOYAGE — Premium Highway Bus Booking Portal

LUXEVOYAGE is a responsive, modern, dark-gold themed luxury bus booking web application featuring a showcase of 10 premium long-distance multi-axle sleeper buses across top routes.

![LUXEVOYAGE Preview](https://images.unsplash.com/photo-1544620347-c4fd4a3d5957?q=80&w=1200)

---

## ✨ Features

- 🚍 **10 Premium Fleet Showcase**: Filter by Volvo Multi-Axle, Scania Metrolink, and Executive Sleeper Coaches.
- 🎨 **Dark Gold Luxury Design**: Custom typography, glassmorphism UI components, and subtle hover animations.
- 🎯 **Interactive Filtering**: Dynamic JS filtering without page reload.
- 📅 **Modal Reservation System**: Interactive quick-booking request modal form.
- 📱 **Fully Responsive Layout**: Built with CSS Grid and Flexbox for mobile, tablet, and desktop viewports.
